# 348-MAKTAB

Onlayn maktab va til markazi platformasi (React + Vite + Express).

## Ishga tushirish

1. `npm install`
2. `.env.example` faylini `.env` ga nusxalang va kerakli qiymatlarni kiriting (`GEMINI_API_KEY`, `SESSION_SECRET`, ...)
3. Dev rejimi: `npm run dev`  → http://localhost:3000
4. Production: `npm run build` va `npm start`
